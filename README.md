# A股千选 · 行业研究台

1000 只 A 股的静态研究快照，按同花顺 90 个行业目录展示。排除 68 开头、ST 和退市标识，评分包含财务、估值、成交、换手率与近 30 日涨停频次。

行情截至 2026-10-09；页面不会自动刷新。评分是研究优先级，不代表未来收益。

页面支持手动添加股票、从清单移除股票，以及恢复已移除的股票。手动添加只填写代码、名称和行业，不获取行情或模型评分，也不会改变原始前 1000 名的排名。修改保存在当前浏览器的本地存储中；换设备或清除网站数据后不会同步。

本仓库只包含 GitHub Pages 所需的公开静态文件，不含 API 证书或原始数据缓存。

在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root) 即可发布。
